# Spotify-Analysis
This Spotify Dashboard project analyzes user engagement trends through albums, tracks, and listening patterns using interactive visualizations. It includes dynamic grids, drill-down capabilities, and year-over-year growth insights to enhance data exploration and decision-making.

🎧 Spotify Data Analysis Dashboard (Power BI)
📊 Project Overview
This project aims to deliver a Power BI dashboard for analyzing Spotify listening data, focusing on user engagement, track popularity, and trends over time. The dashboard leverages various KPIs and visualizations to help uncover actionable insights about listening behavior, track performance, and platform usage.

Note: While the original analysis was created in Microsoft Excel, this README reflects its Power BI implementation for greater interactivity and scalability.

🧠 Business Objective
Understand listening behavior and engagement patterns on Spotify.

Visualize key trends in track popularity, listening time, and customer preferences.

Support better decision-making for music recommendation strategies, marketing, and content planning.

📌 Key KPIs
Total Sales / Streams: Overall number of listens or revenue.

Average Sales / Listening Time: Average engagement per track.

Number of Items: Total tracks or albums analyzed.

Average Rating: Mean user rating per track (if available).

📈 Dashboard Components
1. Total Sales by Fat Content
Objective: Understand how content types (e.g., genre or mood) impact engagement.

Chart: Donut Chart

2. Total Sales by Item Type
Objective: Analyze how different music types (singles, albums, podcasts) perform.

Chart: Bar Chart

3. Fat Content by Outlet for Total Sales
Objective: Compare content performance across different platforms or user types.

Chart: Stacked Column Chart

4. Total Sales by Outlet Establishment
Objective: Analyze how platform maturity affects usage.

Chart: Line Chart

5. Sales by Outlet Size
Objective: Evaluate platform size vs. performance.

Chart: Donut/Pie Chart

6. Sales by Outlet Location
Objective: Understand regional listening behavior (Tier 1/2/3 cities).

Chart: Funnel Chart

7. All Metrics by Outlet Type
Objective: A comprehensive view of all KPIs by outlet or platform type.

Chart: Matrix Card

🔍 Additional Insights
📅 Yearly Trends
LY vs PY: Comparison between Latest Year and Previous Year.

YoY Growth: Year-on-year changes in listening behavior.

🕒 Listening Patterns
1. Listening Hours Heatmap
Identify peak times and days (e.g., morning commutes or late-night sessions).

2. Quadrant Analysis
Avg Listening Time vs. Track Frequency:

High-High: Highly engaging tracks

High-Low: Popular short tracks

Low-High: Niche long tracks

Low-Low: Low engagement content

🧾 Details Grid
1. Essential Fields View
Album, Artist, Track, Genre, Duration, etc.

2. Drill-Through & Drill-Down
Click to explore deeper layers.

Navigate between summary and detailed views.
